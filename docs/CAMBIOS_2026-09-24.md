# ACTUALIZACIÓN DE DOCUMENTACIÓN — NAYRA

## Cambios incorporados

Fecha: 2026-09-24

Se incorporaron las siguientes decisiones al conjunto de documentación del proyecto:

1. **Infraestructura:** Nayra contará con **2 instancias de aplicación**, ubicadas en **zonas diferentes**, para mejorar la disponibilidad.
2. **Entorno financiero:** el proyecto utilizará un **entorno bancario simulado/controlado** para representar cuentas y operaciones.
3. **Bancos reales:** la integración directa con bancos reales queda **fuera del alcance actual**.
4. Las tablas `CUENTAS` y `OPERACIONES` representan operaciones dentro del entorno simulado y no implican movimiento de fondos reales.
5. No se agregaron automáticamente componentes de infraestructura no aprobados. La definición de balanceador, DMZ, VPC, API Gateway u otros componentes continúa dependiendo de la arquitectura aprobada.
